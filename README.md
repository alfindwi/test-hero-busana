# Workflow Test Hero Busana – Frontend

- Project Manager register -> Redirect ke halaman login
- Project Manager login -> Mendapatkan token autentikasi -> masuk dashboard
- Dashboard Page -> Menampilkan statistik tugas (Pie Chart & Bar Chart)
- Task Page -> Menampilkan daftar semua task dan ada button view edit delete -> Project Manager bisa memfilter bedasarkan status -> Tersedia button Create untuk tambah data baru
- Task Detail Page -> Menampilkan Detail lengkap yg di pilih beserta Logs nya

## Getting Started

### 1. Clone the Project

```bash
git clone https://github.com/alfindwi/test-hero-busana.git
cd test-hero-busana
```

### 2. Install Dependencies

```bash
npm install
```

### 3.Konfigurasi Environment

```bash
VITE_BACKEND_URL=
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Jalankan Aplikasi

```bash
npm run dev
```
